# Full CLI conversion (with cli-app-builder skill)

## Entry point and command tree

- Installed console entry point remains `tb-detection-model = "tb_detection_model:main"` and now resolves to the Typer app.
- Module invocation is also available with `python -m tb_detection_model`.
- Commands:
  - `tb-detection-model data build` (recommended ZIP-to-processed-dataset path)
  - `tb-detection-model data validate`
  - `tb-detection-model data extract` (legacy extraction utility)
  - `tb-detection-model data interim` (legacy sampling utility)
  - `tb-detection-model config init`
  - `tb-detection-model config show [--json]`
  - `tb-detection-model config validate`

## Configuration contract

- Root-level file: `tb-detection.toml`.
- Precedence: typed built-in defaults, default `tb-detection.toml` when present, explicit root `--config PATH`, then explicit command options.
- Sections and keys are documented in the checked-in starter file and generated by `config init`:
  - `[paths]`: `raw`, `processed`, `interim`, `report`
  - `[dataset]`: `seed`, `archives`, `archive_assignments`, `split_ratios`, `manifest_filename`
  - `[preprocessing]`: `target_size`, `min_image_size`, `min_mean`, `roi`, `median_blur_kernel`, `clahe_clip_limit`, `clahe_tile_grid`, `train_mean`, `train_std`
  - `[interim]`: `sample_size`
  - `[logging]`: `level`
## Files changed
- `src/tb_detection_model/data/`: packaged workflow modules so the installed
  wheel's console entry point has the existing extraction, interim, builder,
  and validation implementations available (without relying on the repository's
  `src.data` namespace).

- `src/tb_detection_model/cli.py`, `config.py`, `__init__.py`, `__main__.py`: Typer app, typed TOML loader, precedence, command adapters, installed/module entry points.
- `src/data/make_dataset.py`: optional archive selection/assignment and split/preprocessing/manifest settings while preserving the existing processing functions and defaults.
- `src/data/extract.py`, `src/data/create_interim.py`: path, archive, sample size, and deterministic seed adapters.
- `src/data/validate_processed.py`: repaired undefined placeholder configuration and exposed configurable validation/reporting.
- `tests/test_cli.py`: command discovery, config init/show/overwrite behavior, config-vs-CLI precedence, and invalid configuration coverage.
- `tb-detection.toml`: generated root-level starter configuration created by
  `config init` (not committed in this implementation).
- `pyproject.toml`, `uv.lock`: Typer dependency and lock resolution.
- `AGENTS.md`, `CONTRIBUTING.md`: synchronized copy-pasteable install, discovery, build, segmented build, config precedence, legacy commands, unsupported paths, and QA commands.

## Unsupported behavior

Training, prediction, feature extraction, and visualization are not exposed as successful commands. Their repository modules are placeholders and the CLI documentation states this explicitly. Archive assignment accepts `ARCHIVE=SPLIT` and preserves patient-group isolation; unsupported/invalid split names fail configuration validation.
